# 📄 Automated Resume Analyzer

> **Status:** ✅ Completed

An AI-powered Resume Analyzer that evaluates resumes against a job description by calculating ATS compatibility, identifying missing keywords, and recommending relevant skills. The application helps job seekers optimize their resumes for Applicant Tracking Systems (ATS) before applying for jobs.

---

## 🚀 Overview

The Automated Resume Analyzer allows users to upload their resume and provide a job description. Using Natural Language Processing (NLP) and the Gemini API, the system analyzes the resume, compares it against the job requirements, and generates actionable insights to improve ATS compatibility.

---

## ✨ Features

- Upload resume in PDF format
- Paste or upload a job description
- ATS compatibility score generation
- Missing keyword detection
- Skill gap analysis
- AI-powered improvement suggestions
- Interactive Streamlit interface
- Instant resume feedback

## ⚙️ How It Works

1. The user uploads a resume in PDF format.
2. A job description is provided.
3. The application extracts text from both documents.
4. The resume is compared against the job description.
5. Gemini analyzes the content and generates:
   - ATS compatibility score
   - Missing keywords
   - Recommended skills
   - Personalized improvement suggestions

---

## 🧠 Core Components

### Resume Processing
- Extracts text from uploaded PDF resumes
- Cleans and preprocesses document content

### Job Description Analysis
- Identifies required skills and important keywords
- Extracts relevant hiring criteria

### AI Evaluation
- Uses the Gemini API to compare the resume with the job description
- Generates intelligent recommendations for improvement

### ATS Optimization
- Calculates resume compatibility
- Highlights missing keywords and skill gaps
- Suggests improvements to increase ATS performance
