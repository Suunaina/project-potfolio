# 🌐 Personal Portfolio Website

A modern, responsive, and recruiter-focused personal portfolio website built to showcase my technical skills, projects, education, and professional journey as a Computer Science Engineering student.

## 📌 Overview

This portfolio serves as my online professional presence, providing recruiters and collaborators with a centralized place to explore my projects, technical expertise, resume, and professional profiles.

The website is designed with a clean Apple-inspired aesthetic, emphasizing simplicity, readability, and ease of navigation while remaining fully responsive across devices.

---

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern minimalist UI
- Dynamic project showcase
- Featured projects section
- Technical skills categorized by domain
- Education timeline
- Contact information with social links
- Resume download
- GitHub, LinkedIn, and LeetCode integration
- Automatic deployment using Vercel

---

## 📂 Website Sections

### 🏠 Hero

Introduces my profile with a short summary and quick navigation.

### 👩‍💻 About

Brief overview of my academic background and interests.

### 💡 Skills

Categorized list of programming languages, frameworks, databases, developer tools, AI technologies, and core computer science subjects.

### 🚀 Projects

Displays completed projects with:

- Project description
- Technology stack
- GitHub repository (when available)
- Live Demo (when available)
- Documentation (Read More)

### 🎓 Education

Academic qualifications and achievements.

### 📬 Contact

Provides professional links including:

- GitHub
- LinkedIn
- LeetCode
- Email
- Phone Number

---

## 🚀 Deployment

The portfolio is automatically deployed using **Vercel**.

Whenever changes are pushed to GitHub, Vercel automatically builds and deploys the latest version.

---

## 🎯 Motivation

Rather than relying solely on a resume, I wanted to create a dedicated platform where recruiters could quickly explore my projects, technical skills, and professional work in an organized and visually appealing manner.

The portfolio is designed to grow over time, allowing new projects, skills, and achievements to be added with minimal effort.
