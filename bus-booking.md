# 🚌 Bus Booking System

> **Status:** ✅ Completed

A database-driven Bus Booking System developed to simplify ticket booking and bus management. The application provides separate functionalities for users and administrators, enabling efficient booking, schedule management, and database operations.

---

## 🚀 Overview

The Bus Booking System was developed as a DBMS project to demonstrate database design, CRUD operations, and user management. Users can browse available buses, book tickets, and manage reservations, while administrators can maintain bus schedules and update system records.

The project emphasizes backend logic, database integration, and efficient data management.

---

## ✨ Features

- User registration and login
- Browse available buses
- Ticket booking
- Reservation management
- Administrator dashboard
- Bus schedule management
- CRUD operations
- Database-driven application

---

## 🛠 Tech Stack

### Programming Language
- Java

### Database
- MySQL

---

## ⚙️ How It Works

1. Users register and log in to the system.
2. Available bus schedules are retrieved from the database.
3. Users book tickets for their preferred buses.
4. Booking information is stored and managed in MySQL.
5. Administrators can add, update, or remove bus schedules and manage booking records.
