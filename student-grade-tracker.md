# 📊 Student Grade Tracker

> **Status:** ✅ Completed

A console-based Java application for managing student records and tracking academic performance. The system allows users to add student information, record grades, and monitor performance through a menu-driven interface.

---

## 🚀 Overview

The Student Grade Tracker provides a simple solution for maintaining student records and organizing academic grades. The application demonstrates object-oriented programming principles while implementing a structured data management system.

---

## ✨ Features

- Add student records
- Store academic grades
- Track student performance
- Menu-driven console interface
- Simple record management

---

## 🛠 Tech Stack

### Programming Language
- Java

---

## ⚙️ How It Works

1. Users launch the application.
2. Student information is entered through the console.
3. Grades are recorded and stored.
4. Student records can be viewed and managed.
5. The application helps organize academic performance data.

---

## 🎯 Learning Objectives

This project demonstrates Java fundamentals including object-oriented programming, collections, user input handling, and menu-driven application design.
