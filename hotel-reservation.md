# 🏨 Hotel Reservation System

> **Status:** ✅ Completed

A console-based hotel reservation system developed in Java that allows users to manage room bookings and reservations through a command-line interface.

---

## 🚀 Overview

The Hotel Reservation System simulates the core functionality of a hotel booking application. Users can reserve rooms, manage bookings, and interact with the reservation system through a simple console interface.

---

## ✨ Features

- Room reservation
- Booking management
- User-friendly console interface
- Reservation records
- Simple booking workflow

---

## 🛠 Tech Stack

### Programming Language
- Java

---

## ⚙️ How It Works

1. The application starts and displays available options.
2. Users enter booking details.
3. Reservation information is processed.
4. Booking records are maintained during program execution.
5. Users can manage reservations through the console.

---

This project demonstrates Java programming concepts including object-oriented programming, user input handling, and menu-driven application development.
