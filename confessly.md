# 🌐 Confessly

> **Status:** ✅ Completed

An anonymous confession platform built using the MERN stack that allows users to securely share confessions while providing administrators with moderation capabilities. The application demonstrates full-stack development with authentication, role-based authorization, and RESTful API design.

---

## 🚀 Overview

Confessly is a web application where users can register, log in, and anonymously post confessions. Administrators can manage submitted confessions through a dedicated moderation interface, ensuring that inappropriate content can be reviewed and removed.

The project showcases complete frontend and backend integration using the MERN stack.

---

## ✨ Features

- User registration and login
- JWT-based authentication
- Role-based authorization
- Anonymous confession posting
- View public confessions
- Administrator moderation panel
- Create, read, update, and delete (CRUD) operations
- Responsive user interface

## ⚙️ How It Works

1. Users create an account or log in securely.
2. Authenticated users can submit anonymous confessions.
3. Confessions are stored in MongoDB through RESTful APIs.
4. Public users can browse approved confessions.
5. Administrators can review, manage, and remove inappropriate content.
