# 💬 AI ChatBot

> **Status:** ✅ Completed

A console-based chatbot application developed in Java that simulates basic conversational interactions. The project demonstrates conditional logic, user input handling, and conversational flow in a simple command-line environment.

---

## 🚀 Overview

The AI ChatBot accepts user input through the console and responds with predefined conversational replies. It serves as an introductory project for understanding chatbot logic, control flow, and interactive Java applications.

---

## ✨ Features

- Console-based interaction
- User input handling
- Predefined conversational responses
- Continuous conversation loop
- Simple and lightweight implementation

---

## 🛠 Tech Stack

### Programming Language
- Java

---

## ⚙️ How It Works

1. The application starts and waits for user input.
2. The user enters a message.
3. The chatbot processes the input.
4. A predefined response is displayed.
5. The conversation continues until the user exits the application.

---

## 🎯 Learning Objectives

This project demonstrates Java fundamentals including conditional statements, loops, user input handling, and basic conversational program design.
